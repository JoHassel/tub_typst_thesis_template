# tub_typst_thesis_template
Thesis Template for TU Berlin written in typst

This typst code contains of three files. 
1.  The `template.typ` file contains all layout definitions.
2.  The `formal_content.typ` file contains the following content:
    * task description
    * abbreviations
    * abstract (English and German)
    * tools 
    * apppendix
3. The `thesis.typ` contains the actual content of the thesis only. This ensures a clean script for better focus on the content-related issues.
